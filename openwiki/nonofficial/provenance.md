# Non-official provenance map

This wiki is produced by a host-native port of langchain-ai/OpenWiki's official `code` procedure, into a
repository that also treats `openwiki/` as a **typed contract surface**. Two different authorities decide
what exists here, and mixing them in one directory made the boundary invisible.

The split is now structural:

```text
openwiki/
  quickstart.md          <- OpenWiki's entrypoint
  architecture/  skill-assets/  validation/  governance/
  operations/    terminal-operator/  testing/  lifecycle/    <- OpenWiki's section shape
  index.md  (per directory)                                  <- OpenWiki's generated indexes
  .last-update.json                                          <- OpenWiki's run metadata
  nonofficial/           <- everything else, this directory
```

**Rule: the wiki root holds only what OpenWiki's own procedure produces. Anything else lives here.**

## Tier 1 — OpenWiki's own design (stays at the root)

| Artifact | Authority |
|---|---|
| `quickstart.md` | the official entrypoint; carries the task-routing table |
| the eight section directories | *"create one directory per major section, for example architecture/, workflows/, domain/, api/, data-models/, operations/, integrations/, testing/"* |
| every `index.md` | reserved OKF document, generated deterministically after each run — never hand-written |
| `.last-update.json` | run metadata (`updatedAt`, `command`, `gitHead`, `model`, `status`) |
| OKF v0.1 front matter on every concept page | `type` required; `title`, `description`, `tags` recommended |
| Mermaid diagrams on flow / lifecycle / data-model pages | official diagram discipline |

## Tier 2 — pinned by this repository's gates (lives here)

### How the relocation was done

Moving these required editing the gates, because they compare literal paths rather than scanning
directories. Every reference was repointed in one pass:

| File | What changed |
|---|---|
| `scripts/check_openwiki.py` | `REQUIRED_FILES`, the `REQUIRED_LITERALS` keys, and the `openwiki.yaml` value literals |
| `scripts/check_plan_package_compat.py` | the required-path list |
| `scripts/check_wiki_graph_sync.py` | two required files and the two pages it reads |
| `scripts/check_lifecycle_datasets.py` | the display-page path |
| `scripts/check_autoresearch_lifecycle.py` | `REPORT` |
| `scripts/check_prompt_trace_assets.py` | the display-page path |
| `scripts/render_lifecycle_openwiki.py` | its write target **and** the dataflow line it emits — the second one matters, because the generated page is byte-compared and a stale dataflow line breaks equality |
| `tests/test_skill_asset_governance.py` | the twelve required paths |
| `README.md` (repo root) | the two `openwiki entry` references |
| `nonofficial/openwiki.yaml` | its own self-referencing page values |
| every wiki page | relative links repointed for the new depth |

`.github/workflows/wiki_graph_sync.yml` needed no change: its filter is `openwiki/**/*.md`, already
recursive, and `scripts/sync_wiki_to_graph.py` walks the wiki with `rglob`.

## Rule for future additions

- Produced by OpenWiki's own procedure → the wiki root.
- Anything else → this directory, and add a row to Tier 2 or Tier 3 above.
- A gate that pins a new page must pin it **under `nonofficial/`**, never at the wiki root.
- If a Tier 2 entry is ever retired from its gate, it moves to the root only if OpenWiki's design
  actually calls for it; otherwise it stays here and its row records that it is no longer pinned.
